🔐 Autenticación vs Autorización & Función del JWT
📝 Diferencias Principales
Autenticación (Login)
¿Quién eres? - Verifica tu identidad

Ejemplo: Login con usuario y contraseña

Como un club: Mostrar tu carnet para entrar

Autorización (Permisos)
¿Qué puedes hacer? - Verifica tus permisos

Ejemplo: Acceder a productos después del login

Como un club: Acceder a áreas VIP con tu carnet

🎫 Función del Token JWT
El JWT es como un pase de acceso temporal que:

✅ Sustituye tu usuario/contraseña después del login

✅ Contiene tu información (ID, email, permisos)

✅ Se envía automáticamente en cada petición

✅ Protege las rutas del backend

✅ Expira después de un tiempo por seguridad
