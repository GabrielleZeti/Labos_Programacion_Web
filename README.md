Ejercicio 2 – Flexbox

Pregunta 1: ¿Por qué cambia el posicionamiento de las cajas internas al div principal?
Porque Flexbox distribuye los elementos según la propiedad flex-direction y el espacio disponible, no de forma fija como los bloques normales.
Pregunta 2: ¿Qué pasa si me piden cambiar el orden de los elementos sin tocar HTML o JS?
Se puede hacer con la propiedad order en CSS, que reordena los elementos visualmente sin modificar el HTML.

Pregunta 3: ¿Qué hace flex-wrap?
Permite que los elementos se ajusten en varias líneas si no caben en una sola.

Ejercicio 3 – Grid

Pregunta 1: ¿Puedo diseñar toda mi web usando GRID?
Sí, porque Grid está pensado para manejar estructuras completas de páginas web con filas y columnas, incluso combinándolo con Flexbox.
Pregunta 2: ¿Por qué se logran tantos cambios con tan pocas líneas de CSS?
Porque grid-template-areas y grid-template-columns/rows permiten definir toda la disposición en pocas propiedades, sin necesidad de modificar el HTML.

Ejercicio Final

Pregunta implícita: ¿Cómo hacer que un componente aparezca con animación y el botón cambie al pasar el cursor?
Con keyframes para animar la entrada y con :hover + cursor:pointer para el botón.
