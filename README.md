¿Qué significa className en React?

Es el equivalente de class en HTML normal

Se usa porque class es palabra reservada en JavaScript

¿Las props tienen un límite?

No hay límite técnico en la cantidad de props

Se pueden pasar tantas como sean necesarias

¿Quién define las props?

El componente padre define qué props enviar

El componente hijo define qué props espera recibir

¿Por qué se comporta igual que HTML puro?

Porque React compila los componentes a HTML real que el navegador puede entender

Los componentes son abstracciones que facilitan el desarrollo
