Pregunta 1 (Página 8)
¿Qué ocurre con los operadores y por qué JS permite esto?

Análisis:
inicio (pre-incremento): Incrementa primero, luego devuelve el valor

inicio (post-incremento): Devuelve el valor primero, luego incrementa

Operadores compuestos (+=, *=): Atajos para operaciones comunes

Por qué JS lo permite?
Eficiencia: Código más compacto y legible

Estándar universal: Operadores comunes en muchos lenguajes

Expresividad: Permite operaciones complejas en una línea
